# v1.0.0 preparation (provisional)

Software for "When ranking is not enough: selecting deployment cutoffs for OCR post-correction under generator and population shift". Preserves the final corrected VF2 implementation and its real imported dependencies, including prompts, parsers, scorers, configurations and tests. Frozen figure/table replay is supported by separately supplied Online Resource 3.

The evidence is a corrective re-analysis of previously observed test outcomes. Grouped intervals are descriptive per-quantity intervals; the procedures provide no established finite-sample deployment safety certificate. Source corpus text/images and model weights are not redistributed. Historical script names survive only where required as implementation dependencies, not as current scientific evidence.

Final manuscript reconciliation, manuscript authors, material licence approval and full quality gates remain outstanding. No final release tag or DOI has been created. The frozen Python package version remains 0.1.0; v1.0.0 is the proposed artifact release version.
